# 心育采购观察

心理健康教育 G/B 端公开采购情报 HTML 工作台。

- 本周、近一年、单次运行切换；采购单位、地区、日期与金额分口径展示。
- 教育核心、教育相关、其他心理与待核验分组。
- 公告与公开附件的产品、技术参数候选保留原文位置和链接。
- 正文核验与搜索线索分开；不承诺全网全量覆盖，不将计划量当采集量。

本仓库提供公开网站。采集器在本地每周调度运行，核验后生成 `data.js` 并推送；GitHub Actions 负责部署网页，并提供手动触发的公开来源网络对照与公告补抓工作流。每周调度仍由本机任务协调，需要运行电脑及网络可用。

金额为规则提取候选；采购意向批次、同类型冲突金额及未核验线索不计入汇总。主体性质和分类仍需业务复核。本地查看请启动静态 HTTP 服务；正文与历史运行文件按需读取。

网站覆盖页区分来源登记、连接探测、域名检索和实际正文取得；不能把首页200或搜索命中当年度完整覆盖。
