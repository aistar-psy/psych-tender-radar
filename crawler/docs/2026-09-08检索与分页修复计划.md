# 检索、分页与零线索诊断修复

用户要求沿用V1.3关键词式，逐一解释聚合网站漏数和省级公共资源零线索。

已确认：上轮剑鱼、采招网、千里马分别仅有一条“心理健康 教育 采购”外部索引查询；source_scan生成的固定6个短查询未使用原A—F式；静态链接扫描没有站内检索适配。省级零入库在程序中只依据外部索引与当前入库结果，不构成站内无项目证据。

1. 从原任务包只读提取A—F式与8词族，保留源哈希和原式。将OR拆为并集、AND保留交叉；记录原式ID、字段、拆分查询与本地二次匹配，不能额外强制所有词同时出现“心理健康+教育+采购”。
2. 通过真实普通浏览器检查站内检索、关键词字段、原始总条数和后页访问。登录/验证码/脚本未加载/请求失败分别记录，不绕过。
3. 对省级公共资源零正文入口逐个检查连接、检索页面与公开索引。用已知阳性公告检验索引与解析链条；站外空结果不作为站内无信息的结论。
4. 补齐可访问公开检索和分页处理，记录游标、页数、重复页、后页失败、日期窗口。只有关键词、日期、结果页全部验证才可说指定范围内无匹配。
5. 新候选保留检索证据与旧库去重，正文抓取和分类后更新HTML；来源表增加检索方式、A—F执行进度、分页和具体缺口。执行回归测试、浏览器验收后发布并更新每周任务。
