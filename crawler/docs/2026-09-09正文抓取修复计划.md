# 正文抓取修复

范围：重新处理当前近一年 977 条缺正文线索，沿用 V1.5 词库，不扩大关键词范围来代替正文补抓。

已复现：Python 请求陕西公告出现证书校验错误；重庆返回 403。同样地址在正常 Chrome 中均可读取采购正文。

实施顺序：

1. 对照系统证书库的 HTTPS 请求，保持证书校验开启；批量请求保留完整错误类别、状态码、时间和最终网址。
2. 将失败、验证提示和动态页面纳入普通浏览器补抓队列，支持断点续跑、每站限速、渲染等待和原始响应留存。遇未能完成的验证明确记录，不算正文已取得。
3. 从正文识别实际发布源和公开附件，继续下载与父公告关联；扫描件和会员摘要不充当详细正文。
4. 用同一解析器重放缓存，核对项目名称、日期、金额、采购单位、供应商和命中依据，排除无关内容。
5. 将具体采集失败原因写入列表和详情；生成本周及年度统计、修复前后对照报告，保留统计边界。
6. 执行回归和浏览器验证，更新公开源码及 GitHub Pages，核验线上数据版本；更新每周任务调用新的补抓流程。
