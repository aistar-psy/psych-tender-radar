# 全国招投标来源覆盖补强

用户已授权补全既有招投标采集与发布。原两个单页栏目和关键词抽样不足以支撑全国年度完整性，必须修复来源层与证据层。

1. 官方目录：从中国政府采购网地方分网与全国公共资源交易平台省级链接提取实际URL，扩展全国、省级、计划单列市、兵团。来源官网验证与正文采集验证分开。
2. 全国来源执行器：逐站探测、站内心理采购栏目/公开接口、分页/时间窗口/检索词；无可用接口时使用明确登记的域名限定搜索并保留缺口，不能将首页200当采集成功。生成每站结果、页数、候选数和失败原因。
3. 历史补抓：真实执行每省/平台检索，与前次候选合并去重，读取新增正文/附件；保留检索日期证据和链接。非公开/验证码服务标受限，不能自动购买或联系供应商。
4. 网站：新增来源台账及实际检索记录，计划/已探测/已检索/已读取/待接入分离；去除将已解析正文等同字段全部核验的歧义。持续扩大年度归档，不能声称所有网站或所有项目均完成。
5. 验收：执行器去重、域名约束、空响应/错误响应、分页预算和断点测试；真实站点试跑；浏览器验证表格与筛选；发布并更新每周任务。

Ruling: 用户已要求完善脚本和覆盖全国网站并授权持续发布，沿用现有产品设计实施，不再要求重复确认。商业信息网站可见公告纳入线索，登录付费权限未获授权时列为来源缺口。
