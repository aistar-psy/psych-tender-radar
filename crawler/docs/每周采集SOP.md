# 心理健康教育采购雷达 · 每周采集SOP

规范版本：SOP-2.0；当前词库：V1.7；更新：2026-10-26。

SOP是操作规范。浏览器中的人工复核不是机器执行回执；配置升级不表示历史数据已按新版回补。

## 范围与边界

- 全国基础发现：31省级地区＋兵团，国家、省级及地市平台。逐站登记和分支/分页记录；未核实完整年度覆盖即标部分。
- 重点地区深抓：按业务优先级配置地区、地市、采购单位及代理。意向、采购、需求、更正、结果、合同分别检索，不能只查采购意向。
- B端公开采购：民办教育、企业、国企及公开供应商采购渠道。身份与用途分开记录；企业全量库尚未建立，权限与会员限制保留缺口。

## 统一版本与范围

输入：最新获授权词库、上一批完成回执、失败与断点队列；31省级地区及兵团、采购公告类型、教育与B端来源清单。

- 比对版本、更新日期和SHA256；旧任务包不能覆盖新版配置。
- 分别建立最近完整周、本周截至采集日和近一年窗口；周增量增加滚动重查，覆盖迟发或迟收录公告。
- 全国基础发现、重点地区深抓和B端公开采购分别登记；政策、新闻、名录不进入市场项目数。

产物：批次ID、北京时间窗口、词库SHA、来源清单、年度与增量计划。

完成条件：上述元数据齐备；计划数量与已执行数量分开。新版原式差异回补已列入队列。

失败处理：版本不一致先核对；旧版拒绝导入。未完成来源登记和时间定义则不进入检索验收。

在项目根目录运行；“本轮独立批次”等占位值须替换。

```sh
./run.sh plan
.venv/bin/python scripts/prepare_sop_plans.py
```

## 多源检索与分页

输入：当前A—F完整原式、站内适配器、官方平台、商业聚合、采购单位官网和独立母包宽种子。

- 原式按网站、逻辑分支轮转执行；标题/全文字段范围不能丢失。记录分支ID、SHA、日期、页码、报告总数、重复页和停止原因。
- 搜索引擎只补发现，结果没有收录不等于网站无项目；首页HTTP200不等于结果区加载完成。
- 保留原串C；另用母包词发现标题未写心理的大标，取得正文和附件后判断心理子包。每个来源同时只跑一个进程。
- 聚合站公开分页上限、登录、会员、验证或加载失败均保留缺口；不把可见前500条当全部结果。
- 正常浏览器脚本需按README准备Node、Playwright和Chrome；PLAYWRIGHT_MODULE使用实际安装位置。江西TLS兼容错误转正常官网浏览器，不关闭证书校验。

产物：候选URL、真实标题、日期证据；逐站原式及分页日志，下一页断点。

完成条件：候选和页面标题/URL对应关系有证据；成功、失败、未执行分别统计。完整年度覆盖没有核实时保留“部分”。

失败处理：连接失败、控件未适配、动态结果未加载、权限提示、页数上限分别记原因；公开源头与同省正例交叉查找。

在项目根目录运行；“本轮独立批次”等占位值须替换。

```sh
.venv/bin/python -m radar.source_scan --max-pages 8 --workers 4 --timeout 10
.venv/bin/python -m radar.keyword_scan --max-queries 192 --max-pages 3
.venv/bin/python -m radar.native_search --source ggzy-jiangxi --max-pages 80 --resume
.venv/bin/python -m radar.native_search --source ggzy-shaanxi --max-pages 80 --resume
.venv/bin/python scripts/prepare_browser_plans.py
PLAYWRIGHT_MODULE=playwright node scripts/cq_browser_search.cjs
PLAYWRIGHT_MODULE=playwright node scripts/jianyu_browser_search.cjs
.venv/bin/python scripts/prepare_native_backfill.py
```

## 正文、附件与源头取证

输入：已核对标题与URL的候选、搜索摘要不足队列和上轮待补正文。

- 依次尝试普通HTTPS、正常浏览器渲染、真实“查看原文”链接和公开附件；凭完整项目名/编号核实同一公告源头，不猜测URL。
- 下载成功后检查采购正文是否有效；动态壳、会员摘要、掩码、验证码页不能算详细正文。
- 保留原始响应、SHA256、读取时间、正文和产品参数所在段落/表格/页码；去除推荐导航。
- 本机失败可用已授权云端公开GET补抓；附件独立批次，扫描件单列需OCR，登录/付费内容停止并记录。

产物：正文与附件证据、真实源头关系、正文状态、失败原因及下一步。

完成条件：已取得正文必须有可加载的有效采购文本；参数关联到原文位置。缺失附件与公告正文分别标记。

失败处理：保留失败URL与分类，不把缓存未命中当网络失败；摘要和会员页面仍待补，不能静默丢弃。

在项目根目录运行；“本轮独立批次”等占位值须替换。

```sh
./run.sh run --weekly --no-discovery --seed-file 候选队列.json --max-documents 1000 --max-attachments 8 --max-seconds 3000
.venv/bin/python -m radar.web_export
.venv/bin/python scripts/recover_pending_notices.py --batch 本轮独立批次
.venv/bin/python scripts/trace_public_sources.py
.venv/bin/python scripts/replay_saved_evidence.py
```

## 分类与项目归并

输入：有效正文、采购人、项目编号、来源、所有公告阶段。

- 按实际采购对象与用途分教育核心、教育相关、其他心理、非目标；学校或医院名称不是唯一分类证据。采购主体G/B性质另记，未知保留未知。
- 标题、正文和附件中的命中词/对位点关联证据；宽词如沙盘、健康画像只作线索，结合实际内容复核。
- 项目与公告分层；同项目招标、更正、结果、合同和重招保留各自事件。编号、项目名、主体与来源相互验证，防止误并。

产物：项目记录、各阶段公告、分类依据、命中词/对位点和排除原因。

完成条件：分类有采购用途证据；项目公告关联能复核，不能只凭相同编号合并冲突采购人。

失败处理：推荐导航污染、跨词误命中、新闻政策和企业名录退出项目统计；身份或归并不清单列待核验。

## 时间、供应商与金额复核

输入：正文中的明确字段与已关联的更正、废标、结果和合同事件。

- 拆开公告发布、预计采购月份、报名/响应截止、开标、合同签订日期；未知不从搜索日期或网页当前时钟推测。
- 预算、限价、成交、合同金额分别记录币种、单位和原文；批次意向、同类矛盾多值、搜索金额及更正生效未确认记录不计合计。
- 中标单位只来自明确结果字段；合同乙方标合同供应商。联系方式、评审排名中的未中标人、纯掩码和盖章模板不得冒充供应商。
- 金额汇总与列表都标注口径；项目数量与公告/线索数量分别说明，教育与其他心理分开统计。

产物：完整项目字段、金额是否可汇总及原因、供应商证据、日期口径。

完成条件：字段均有来源或明确缺失；废标/更正不会继续计旧成交，金额不跨口径相加。

失败处理：矛盾字段保留各自证据并排除样本合计；回到源公告或更正文本复核。

## 报告、项目库与发布

输入：复核后的项目、正文文本、来源执行日志和缺口队列。

- HTML显示本周截至采集日与最近完整周的数量、各口径金额和采购单位；同时展示近一年明细及补抓前后变化。TOP5只作推荐，不代替全列表。
- 项目库包含项目名称、编号、采购人和身份、中标/合同供应商、各类时间与金额、来源、命中词/对位点、正文状态及原始公告超链接。
- 验证组合筛选、详情正文真实加载、原文新标签页、年度与首页往返及移动端。
- 仅发布筛选后的公开文本和源码；不发布原始用户材料、完整浏览器响应、凭据或本地路径。推送后核对Pages工作流、线上builtAt和关键正文文件。

产物：周报、年度明细、项目库、逐站覆盖情况、发布提交和线上验收回执。

完成条件：必要回归通过，线上时间与本地一致，筛选/原文链接/正文均实际可用；失败原因仍能查看。

失败处理：测试、审计或线上版本不一致时停止完成标记；保留已通过步骤与具体故障，不以“已push”当发布成功。

## 失败续抓与执行验收

输入：批次日志、断点、旧待补集合、新待补及本次发布结果。

- 按北京时间自然周存储人工复核；完成必须填写证据或回执。人工填写只代表复核记录，不能触发或证明爬虫运行。
- 连接失败、动态页面、验证受阻、解析待补、扫描件和未执行分别处理，已成功文件复用，失败有上限重试。
- 重算旧待补恢复、仍待补、移出年度窗口、新增待补/降级；条数变化不得全部宣传成新增项目或正文恢复。
- 每轮完成或失败均通知；重复且未变化的中间状态不重复通知。

产物：可追溯回执、按周人工复核、失败原因和下一轮断点。

完成条件：完成声明有真实日志与产物；未完的原式、分页和正文明确保留。

失败处理：日志或证据缺失时状态为待复核/部分完成；本地保存失败明确提示，可导出备份，不能显示虚假已保存。

## 词库与业主清单回顾

输入：真实公告标题、正文、需求附件、产品参数、分类误报和已核实业主。

- 候选词来自标题、正文、附件与产品参数，记录来源及新增理由；用命中和误报样本验证后才入正式词库。
- 词族、A—F原式、脚本、页面和自动化提示同源更新；展示版本、日期、SHA和新增/移除差异。
- 政策与行动名用于发现，不作为采购项目；每月复核业主清单。新版本生成差异检索与近一年补抓计划，执行之前不能记完成。

产物：版本化词库、差异计划、回归样本、业主增补依据。

完成条件：无版本倒退，所有入口显示同一当前配置；历史数据仍标实际版本。

失败处理：新词误报高时保留候选、加强全文核验；不靠不断添加宽词掩盖分页或正文抓取故障。
