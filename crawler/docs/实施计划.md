# 采购雷达实施计划

Goal: 独立运行的公开采购发现、详情提取和分组周报。
Architecture: 模块化Python命令行，SQLite持久状态，JSON配置，Markdown报告。
Spec: 方案.md。

1. 文档与分析模块：先写unittest，覆盖教育/医疗/普通物资分类、HTML表格定位、日期预算及附件；实现documents.py和analysis.py，运行测试。
2. 发现模块：先写地区轮询及发现结果测试；实现discovery.py、复用词库并登记来源；检索失败必须显式返回。
3. 抓取和数据模块：本地HTTP测试先验证200/403/大文件/重复入库；实现fetch.py和store.py，保留公告版本及失败待补。
4. 管线与报告：用本地站点端到端测试发现附件，保留参数来源，失败不当零命中；实现pipeline.py/report.py/cli.py。
5. 实际验证：联网抓取原报告可访问公开公告，保存证据和报告；检查声明与实际取得范围一致。
6. 运行交付：README、requirements、启动脚本、独立周度任务；复核可用调度工具后设置每周一09:00。保留原WorkBuddy任务不擅自修改，提醒避免重复产出。

执行记录存于进度.md。模块可独立开发，采用subagent-driven-development分工及审阅；原项目无修改。
